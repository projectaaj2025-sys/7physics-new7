Алгоритм Евклида для многочленов

Подробные решения задач 578 и 579 — деление «уголком» без пропусков, выражение остатка и обратный ход.
Все деления выполнены в столбик, остаток выражен как r = fi − q·fi+1, далее он становится новым делителем.

Оглавление

Задача 578: подобрать M1(x), M2(x) так, чтобы f1M2 + f2M1 = δ(x), где δ(x) — НОД(f1,f2).

Задача 579: подобрать M1, M2 так, чтобы f1M2 + f2M1 = 1 (многочлены взаимно просты).

Обозначения: rk — остатки Евклида, qk — частные. Для каждого шага показано деление уголком по шагам (без сокращений), затем формула остатка. В конце — обратный ход и коэффициенты Безу: δ = f1·s + f2·t, где s=M2, t=M1. Для проверки выполнено умножение и сложение.
Как читать деление уголком: слева — делимое, справа от вертикальной черты — делитель, под горизонтальной чертой — частное. Под делимым пишется произведение первой части частного на делитель, подчёркивается, вычитается; вниз сносится следующий «треугольник» (член). Процесс повторяется, пока степень текущего остатка < степени делителя. Все промежуточные вычитания показаны последовательно — «без преобразований».

Общие замечания

  • НОД определён с точностью до ненулевого постоянного множителя. В ответах приведён монический (старший коэффициент 1) вариант δ(x). Любой вид c·δ(x) допустим — достаточно домножить M1,M2 на c.
  • Решение (M1,M2) не единственно: если (M10,M20) — частное решение, то общее даётся формулами M1=M10+t·f1/δ, M2=M20−t·f2/δ, где t(x) — любой многочлен.
  • Во всех делениях показано вычитание «без преобразований»: сначала умножаем весь делитель на очередной моном частного и только потом вычитаем. Промежуточные остатки не упрощались заранее.
  • Проверка каждого примера выполнена прямым умножением и сложением — результат совпадает с заявленным δ(x) (или 1).
